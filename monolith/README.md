# Cardok - Monolith

Este diretório contém o núcleo da aplicação **Cardok** (Laravel 10, PHP 8.2+), responsável pela validação, orquestração de provedores externos, cálculo de juros de mora e simulação de pagamentos de débitos veiculares.
